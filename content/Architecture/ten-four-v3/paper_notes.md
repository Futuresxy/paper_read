## 1. 摘要

本文提出 Ten-Four：一个面向开源 RISC-V Vortex GPGPU Tensor Core 扩展的“融合点积单元”（FEDP）微架构。核心目标是替代开源生态常见的“离散乘法器+离散加法器/FMA”拼接方案，降低延迟、减少多次舍入误差，并改善面积与资源利用。Ten-Four 在同一管线内统一支持 TF32/FP16/BF16/FP8/BF8/INT8/INT4 乘法与 FP32/INT32 累加，加入 MX（Microscaling）格式支持、双边稀疏场景的 lane 级时钟门控，并保持与 NVIDIA Tensor Core 参考结果比特一致（作者给出的随机与边界测试）。实现上采用 4 级流水（乘法与异常、对齐、多操作数累加、规格化舍入），通过共享乘法器、差分矩阵找最大指数、CSA/KSA 树、以及整数加数拆分策略复用关键硬件。结果显示：在 U55C FPGA、300MHz 下单 Tensor Core 峰值 130.368 GFLOPS；相对 HardFloat/FPnew/Xilinx DSP 后端速度提升约 2.7×–7.9×，且面积开销低于对手（文中称不到其 60%）。7nm ASAP7 综合达到 1.58GHz 与 2.771 TFLOPS/W（峰值）。

## 2. 背景知识与核心贡献

研究问题来自一个现实落差：商业 GPU Tensor Core 已在混合精度、稀疏和低位宽训练/推理上快速演进，但开源 GPGPU 常停留在“可用但不高效”的原型。论文指出，主流开源方案多依赖 Berkeley HardFloat、FPnew 这类通用浮点库进行模块拼装。此路径优点是工程可复用、IEEE 语义完整，但在 Tensor Core 这类“短时延+高吞吐+多操作数归约”的场景会暴露三个问题：一是流水级数长、单次 MMA 延迟高；二是中间结果多次舍入，误差累积；三是对 FPGA/ASIC 资源利用不理想。与此同时，产业已引入 2:4 结构化稀疏与 MX block floating 量化，开源实现若不原生支持会进一步扩大差距。

Ten-Four 的贡献可理解为“把面向专用点积的算术结构，系统化移植进可配置 GPGPU Tensor Core”。它不仅做浮点 fused dot product，还把整数路径与浮点路径融合，避免双执行单元仲裁和调度开销；同时提供 MX 缩放因子补偿、以及稀疏 lane 时钟门控。作者在表 I 中把自己放在“开源、可配置、多格式、整数融合、微缩放、稀疏门控”六维能力交集的位置。需要注意，论文的性能主张分属不同层次：有 FPGA 实现结果、有 ASIC 综合/后端结果、也有与 NVIDIA 的“等配置归一化对比”。后者属于基于公开参数的比较，不是同平台实测。解读上，这项工作最重要的学术价值是把“离散运算库拼接”升级为“面向 WMMA 数据流的融合数据通路”，从而把精度语义、时延和资源三者一起优化。

## 3. 核心技术和实现细节

### 0. 技术架构概览

Ten-Four 的端到端数据流可概括为“寄存器分块输入 → 融合4级FEDP → 结果回写”，并嵌入 Vortex SIMT 子核的 TCU 扩展。

首先，warp 内线程寄存器共同承载 A/B/C 子块。按格式不同，每个32位寄存器打包元素数不同（如2×16b、4×8b、8×4b），因此同一 FEDP 网格要适配不同 K 维长度。进入 FEDP 后，第1级同时做三件事：共享乘法（按尾数位宽分组，如 FP16/BF16/TF32 共享11×11 WTMUL；FP8/BF8 走4×4并局部求和）、指数和偏置换算、异常检测（NaN/Inf/0×Inf等）。与此同时构造指数差分矩阵，为后续“最大指数”与移位量服务。

第2级完成最大指数选择并进行尾数对齐。该设计不是传统比较树，而是利用差分矩阵和符号关系恢复大小，时间路径更接近常数级（解读：扇出仍会增长）。移位时保留sticky位与额外对齐位，为最终舍入做准备。

第3级是关键：把K个乘积与加数C一并送入多操作数累加，不再“先点积后再加C”。负数处理采用“按位取反+统一修正项”代替逐项补码，修正值来自符号位popcount，随后交给CSA树（小规模标准CSA，大规模MOD-4分组CSA）。这一步显著缩短关键路径并减少额外舍入。

第4级做规格化与RNE舍入，异常时输出IEEE约定结果。整数融合路径在第2级多为直通，重点复用第3级累加器；为容纳INT32加数C，作者将C拆成低25位（入CSA）与高7位（后级并行补偿），在低开销下得到完整INT32。

此外两条“旁路机制”很重要：其一是稀疏lane mask，若A或B元素为零则前级寄存器时钟门控，进入跨lane归约前再AND清零，避免脏值；其二是MX支持，把缩放从“和后统一乘”改写为“逐lane先补偿再求和”，从而兼容早期并入C的融合策略。

### 1. 差分矩阵最大指数选择

Ten-Four 用“指数差分矩阵”替代传统比较树来找多操作数中的最大指数。做法是并行计算各操作数指数两两相减，利用结果符号位表示大小关系，再经 AND/NOR 逻辑推出最大值索引（one-hot）。作者还利用矩阵对称性：只算上三角，另一半由符号取反推得，节省面积。该方法好处是比较深度不随N线性增长，Stage-2 还能复用差分结果快速得到各项移位量，减少额外比较器。代价是面积复杂度趋向 O(N²)，当N大时布线与扇出会增加，实际时序仍可能受物理实现影响。算例上，若有K个乘积再加C，总操作数为K+1，系统需统一对齐到最大指数；一旦最大指数错判，后续右移会造成严重精度损失，因此该模块与异常通路并行运行以尽早锁定边界条件。解读：这是一种“用面积换关键路径稳定性”的策略，适合点积里并行输入较多但位宽适中的场景。

### 2. 加数早融合与统一补码修正

论文反对“先算点积再与C相加”的朴素流程，因为那会多一次对齐、规格化与舍入，不仅延迟高，还放大舍入误差。Ten-Four 在Stage-1就把C纳入最大指数竞争，在Stage-2同步对齐，Stage-3直接与乘积一起做多操作数归约。更关键是负数处理：不是每个负项都单独做二补码(+1)，而是统一只做按位取反，把所有“+1修正”聚合成一个额外操作数，其值等于负项个数（popcount）。这样可减少加法链中的进位传播压力，配合CSA树更友好。代价在于控制逻辑略复杂，需要保证符号统计与sticky位逻辑严格同步，否则会出现低概率边界错误。算例（概念）：若6个输入里有3个负数，传统要3次+1，Ten-Four把这3次合成一个“+3”输入进CSA。解读：这是把“分散的小修正”变成“集中修正”，在点积归约电路里常能换来更短关键路径。

### 3. 整数/浮点融合与C拆分策略

Ten-Four 不做两套独立执行单元（FP与INT），而是尽量复用浮点点积主干，尤其复用最昂贵的Stage-3累加器。难点在INT32加数C位宽较大，超过该级累加宽度（约25+log2(2K)位）。作者提出拆分：低25位随乘积进入CSA，高7位（C_HI）延后传递。到最终级时，将累加器溢出的符号扩展高位与C_HI并行相加，再与低位拼接，输出完整INT32。优点是避免大位宽扩展贯穿中间流水，降低寄存器与布线成本；同时保持FP/INT共享主体结构。取舍在于：需要额外验证高低位拼接与溢出语义，在极端边界值下必须保证与参考实现一致。论文通过100万+向量比特一致测试支持其正确性。解读：该策略属于“位宽分层处理”，非常适合在统一数据通路里压缩关键资源，但需要更严格形式验证来覆盖角落情况。

### 4. 双边稀疏下的lane时钟门控

作者指出内积型Tensor Core在双边稀疏下会出现“无效lane”问题：即使A、B都稀疏，仍可能有部分乘法位点被结构限制无法利用。与DSTC外积方案相比，外积虽能绕开该限制，但需存M×N中间部分和，面积代价大。Ten-Four 采取折中：保持内积结构，仅做功耗优化。具体是依据输入格式与零检测生成valid mask：前两级对无效lane进行时钟门控，减少翻转；进入跨lane归约前，再把对应数据AND为0，防止旧值污染CSA。实验显示该方法在高稀疏更有效：70%仅约5–11%动态节省，90%可达35–48%，100%约68–71%。INT4在>70%稀疏处偶尔不如INT8，论文解释为细粒度门控控制开销占比上升。解读：这不是“稀疏加速”而是“稀疏省电”，与2:4结构化稀疏可叠加但收益维度不同。

## 4. 实验方法与实验结果

论文实验分为五块：FPGA性能/面积、稀疏功耗、ASIC综合与物理实现、数值正确性、端到端 roofline。整体证据链较完整，但主要是实现评估与建模，不含大规模训练任务的最终模型精度（如 Top-1、Perplexity）。

### 1) 任务与设置
- **硬件平台（FPGA）**：AMD Xilinx Alveo U55C，目标 300MHz。
- **比较对象**：等价 TCU 后端的 HardFloat、FPnew、Xilinx DSP IP。
- **线程配置**：NT=4/8/16/32（对应 4 元或 8 元 FEDP）。
- **稀疏功耗实验**：64×64×64 SGEMM，双边稀疏 0–100%，步长10%，SAIF 后仿功耗估计。
- **ASIC**：ASAP7 7nm PDK，Design Compiler + ICC2，目标约 1.5GHz，给出 GDS/功率密度。
- **正确性**：PyTorch+CUDA 生成 WMMA/PTX，以 RTX4090 Ada Tensor Core 为参考，100万+随机向量与异常值。

### 3) 数值精度与模型层证据
论文给出表III，与V100/A100/H100/B200的分析模型比较，Ten-Four在子正规输入输出支持、乘积对齐位宽等指标上接近新代GPU，且采用 RNE（文中写 RTN-TE，含OCR/排版歧义，解读为 Round-to-Nearest-Even）。这部分强调“行为匹配与IEEE兼容处理”，而非完整DNN训练收敛对比。

### 4) Roofline结果
在Vortex等效1个SM配置下，256³ SGEMM：FP32基线仅约2.3%算力利用，低精度TCU版本进入计算受限区，利用率 TF32 16.0%、FP16/BF16 29.1%、FP8/BF8 51.1%、MXFP8/MXBF8 47.8%。作者也承认未达到理想算术强度，受调度、访存、寄存器流量等非算术开销影响。

### 5) 局限与不确定性
1. **无流片硅后测试**：ASIC为综合/P&R结果，不等价真实芯片功耗与时序裕量。2. **与NVIDIA比较非同条件实测**：仅等工艺公开参数下的iso-configuration推断。3. **应用层精度缺失**：没有给出端到端模型精度/收敛曲线。4. **个别符号OCR疑点**：如表III“RTN-TE”写法、标准单元库字符串存在排版噪声，不影响趋势判断但细节需以原PDF核对。
