# MASQ: Accelerating Masked Diffusion via Stage-Wise Multi-Precision Quantization 通俗讲解

### 0. 整体创新点通俗解读

可以把图像编辑想成修补一幅画。需要重画的区域要仔细处理，附近边缘也需要细致衔接；离得很远、对新内容影响小的背景，可以用更粗的精度计算。但远处某些物体会通过注意力影响编辑区，例如语义上关联的物体，也需要适度提高精度。

MASQ 先把画面分成四级重要区域，随着去噪接近完成，让一部分背景区域的计算更粗一些。它仍保留上下文处理，并通过调整归一化统计量和注意力概率，减少粗精度背景对重点区域的干扰。

硬件相当于使用同一种窄计算工具：细致任务分四轮做，中等任务分两轮，粗任务一轮。掩码管理器决定哪些地方做几轮，主编辑区始终做细致计算。这个类比只解释工作量和精度的关系；实际系统还需要正确处理有符号数、共享指数、跨区域依赖以及数据搬运。

论文的结果说明这种组织在所测任务中有明显模拟收益，质量接近原始模型；并不表示每张图或每个质量指标都完全不变。

### 1. 感受野膨胀与四阶段精度

编辑区附近的背景像接缝，必须算得比较细，否则粗糙误差会影响新内容。MASQ 给边界外留几圈缓冲带，越远可以越粗。随着图像逐渐稳定，还能降低部分缓冲带精度，核心编辑区始终保留最高精度。

### 2. 注意力细化与全局误差控制

远处也可能有与编辑内容相关的物体，因此只按距离分配精度还不够。MASQ 看注意力关系，把重要远处区域提升一级；计算全局统计时，也尽量不让粗糙背景把重点区域的判断带偏。这些近似需要通过图像质量检验。

### 3. 二比特位串行与有符号重建

一把窄计算工具可以分几轮算长数字。最高一段带有正负号，其余段只是补充低位，所以不能把每段都当成一个独立有符号数。MASQ 的小控制信号告诉乘法器当前是哪一段，确保合起来仍是正确的整数乘法。

### 4. 掩码管理与统一精度广播

掩码管理器像一个小调度员，用很少的标记记录哪些地方要算几轮。计算单元一批批接收同一份激活，配不同权重，在同一节奏下工作。掩码放大、缩小和语义更新都用简单位操作完成，减少管理成本。
