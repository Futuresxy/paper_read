# MixFP4: Enhancing NVFP4 with Adaptive FP4/INT4 Block Representations 通俗讲解

### 0. 整体创新点通俗解读

可以把四比特量化想成用一把只有少数刻度的尺子记录一组数。NVFP4 的尺子在小数附近刻度密、较大数附近刻度疏；这种尺子擅长兼顾少量大数。另一把 E1M2 尺子的刻度均匀，更适合数值比较平坦的组。

MixFP4 每 16 个数试用两把尺子，比较还原后的平均平方误差，然后保留更合适的一把。选择结果写在这组数已有的缩放标签空位中，因此不用多加标签。真正计算时，硬件先把两种读法翻译成同一种内部语言，再使用共同的乘加器。

论文看到的是部分模型误差更小、训练损失更好，以及一个硬件切片增加很小的面积和功耗。它没有证明现有显卡已经能直接跑这种新格式，也没有给出生产推理服务的实际加速比。

### 1. 逐块双候选 MSE 选择

同一层像一个装着许多数值小袋子的箱子。整箱只选一把尺子，无法照顾每袋差异。MixFP4 每袋都试两把尺子，把记录值还原后比较误差，保留更准确的一种。峰值因子只是帮助理解为什么要试两种，实际选择仍靠误差。

### 2. 缩放符号位复用与真实兼容边界

每个小袋子原本就有一张缩放标签，标签上有一格一直空着。MixFP4 用这格写“用了哪把尺子”，所以不必再贴一张标签。读标签的机器仍要升级，否则它可能把这个标记误当成数值的一部分。

### 3. E2M2 统一内部表示与局部硬件改动

两种刻度记录的数字先经过一个小翻译器，变成计算器都能读懂的语言。计算器不用准备两整套，但内部数字要稍宽一些，前端也需要判断标签。因此空间和耗电增加很少，却不是完全没有变化。

### 4. 块缩放因式提取与训练集成

一袋数共用同一个放大倍数，就可以先算这些小数字的总贡献，最后统一放大一次。训练还涉及权重更新和梯度，论文给这些步骤配上保留高精度、打散离群值和随机舍入等做法，整套配方一起使用。

### 5. 峰值因子交点和候选格式收益边界

如果一袋数字中只有一个特别大，带指数的尺子通常有用；如果大家差不多大，均匀尺子可能更精细。论文推了一个帮助理解的分界值，但真实数据更复杂，所以仍要试算。袋子变大后，差异更复杂，另一种尺子也可能重新有价值。
