# SEADA: An efficient methodology for optimizing mixed-precision DNNs on multi-precision spatial architectures 通俗讲解

### 0. 整体创新点通俗解读

网络像一组连续工序。有些工序用小数字就够，有些需要更多位来保持准确率；换成小数字后，搬运和计算会变便宜。但注意力、归一化等工序仍可能使用大数字，所以只算小数字乘法会高估节能。

SEADA 先算好每道工序在每种位宽下的成本，再用权重分布的熵估计哪些工序更需要精度。在总预算内把较多位数留给敏感工序，选定后才微调网络。熵可以理解为权重分布的信息复杂程度，它是快速估计工具，而非最终准确率的替代证明。

论文中的“45%方案”指整数加速层预算为8位基线的45%。加上浮点层，BERT整网节能是27.6%，需要保留这两种口径。

### 1. 多精度映射与活动成本库

先为每道工序列一张价格表：2位、4位、8位分别要多少时间和能量。小数可以并排计算，但只能把属于同一输出的乘积合起来。价格表也计入运送数据的成本，之后换预算无需重新模拟全部工序。

### 2. 浮点阶段与量化融合

如果前一道工序的结果要乘一个缩放系数，后一道本来又要乘一个系数，可以先把两个系数合并，不必另跑一次转换工序。这样既少计算，也能直接写回较小数据。但仍要计算注意力和归一化本身的成本。

### 3. 熵引导的分步背包选择

预算有限时，先把高精度留给更敏感的工序。熵给出一张重要程度排序，背包算法在预算内组合选择。三种位宽分两步处理，而共享同一份激活数据的工序要一起决定，避免同一数据出现冲突格式。

### 4. CBR与固定面积存储探索

建筑面积固定，可以给每个工人更多小仓库，也可以保留更大的公共仓库。SEADA尝试这些组合，用已校准的比特减少量判断精度风险，再选择耗时和能量更低的组合。这个指标像筛选工具，最终候选仍需实际微调核实准确率。
